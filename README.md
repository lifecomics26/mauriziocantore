# LIFECOMICS26

Sito statico pronto per GitHub Pages.

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository GitHub, per esempio `lifecomics26`.
2. Carica tutti i file contenuti in questa cartella.
3. Vai in `Settings` → `Pages`.
4. In `Build and deployment`, seleziona `Deploy from a branch`.
5. Scegli branch `main` e cartella `/root`.
6. Salva. Dopo pochi minuti il sito sarà online.

## PDF opuscoli

Sostituisci i file nella cartella `downloads/` con i PDF definitivi usando questi nomi:

- `fumo.pdf`
- `alcol.pdf`
- `disturbi-alimentari.pdf`
- `bullismo.pdf`
- `dipendenze.pdf`
- `ribalta.pdf`
